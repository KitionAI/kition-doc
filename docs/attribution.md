# Asset attribution

Every non-code asset in this repository (fonts, icons, images, example documents) is listed here with its author, source and license. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** This kit contains **no Microsoft, Adobe, Avid or Autodesk iconography, images, templates, themes, clip art, fonts or other assets**. Every asset is original work by this repository's contributors or third-party material under an open license (OSI open source, public domain / CC0, or a Creative Commons license that allows redistribution). Screenshots of other vendors' software are never committed. New font files go to [KitionAI/kition-fonts](https://github.com/KitionAI/kition-fonts), not this repo.

Generated-in-code art is original and has no file to list: the sample documents and templates (`crates/engine/engine/src/sample.rs`), the table and style previews, and theme colours (`crates/engine/engine/src/cmd/design.rs`).
